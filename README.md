# Supply Chain & Inventory Analytics Dashboard | Power BI Project

## Project Overview

This project analyzes supply chain and inventory performance using a Power BI dashboard. The goal is to monitor inventory efficiency, warehouse utilization, transportation cost and order performance.

## Business Problem

Companies need to monitor:

1. Inventory levels
2. Warehouse utilization
3. Lead time
4. Transportation cost
5. Backorders

This dashboard helps decision makers track supply chain efficiency.

## Tools Used

1. Power BI
2. Excel / CSV dataset
3. Data visualization
4. Business analytics

## Key KPIs

1. Warehouse Utilization
2. Inventory Turnover Ratio
3. Days Sales of Inventory
4. Lead Time
5. Backorder count
6. Transportation cost

## Dashboard Insights

Inventory utilization varies across regions.

Electronics and Furniture categories show higher inventory levels.

Most orders are fulfilled while some remain pending.

Lead time varies slightly across product categories.
